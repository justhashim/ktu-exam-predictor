# The student and their exams (template)

Copy this file to `references/student.md` and fill it in. `student.md` is git-ignored, so personal details stay on your machine.

- **Who:** name, branch, semester, scheme (e.g. B.Tech S5 CSE, 2024 scheme).
- **Where materials live:** e.g. `~/Documents/Study Materials/<SHORT>/` (or set `KTU_STUDY_DIR`). Mention folders that already hold your own PDFs.
- **How you like to study:** e.g. topic by topic, saying "next" to move on; worked numericals; exam answer plans; notes page numbers.
- **Anything the assistant should keep in mind:** e.g. a past result, or how much time you usually have.
